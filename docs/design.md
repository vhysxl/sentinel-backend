# 🎓 Eleva

> AI-Powered Learning Management System for K-12 Schools (SD, SMP, SMA)

Eleva is an AI-powered Learning Management System (LMS) designed specifically for Indonesian schools. The platform helps teachers reduce administrative workload through AI-assisted question generation, automated grading, and intelligent student progress reporting.

# 🤖 AI Features

## AI Question Generator

Teachers can upload learning materials and generate:

- Multiple Choice Questions
- Short Answer Questions

Generated questions remain editable before publication.

---

## AI Auto Grading

### Multiple Choice

- Fully automatic grading
- Immediate result generation

### Short Answer

- AI generates:
  - Score
  - Explanation
  - Suggested feedback

Teachers review and approve results before publication.

---

## AI Progress Report

Every month AI analyzes:

- Quiz scores
- Assignment scores *(when available)*
- Attendance
- Submission punctuality

AI generates personalized recommendations for every student.

Homeroom teachers can edit or remove recommendations before publishing.

> **Trigger (current):** Admin manually triggers report generation via a dedicated API endpoint.  
> **Future:** Scheduled cron job (e.g., end of each month).

## Teacher Role Model

In Indonesia, a teacher typically holds multiple roles simultaneously:

- A **homeroom teacher (wali kelas)** almost always also teaches one or more subjects.
- At **SMP/SMA** level: homeroom teacher + subject teacher(s) for specific subjects.
- At **SD** level: homeroom teacher may teach most subjects themselves (e.g., Math, Bahasa Indonesia, IPA), except specialist subjects like English or regional language which are taught by dedicated subject teachers.

Therefore, the system treats teacher roles as **additive assignments on the same user account**, not as separate accounts. A single teacher account can be:

- Assigned as homeroom teacher for a class
- Assigned as subject teacher for one or more subjects in one or more classes

The UI surfaces the appropriate features based on which roles are assigned.

# 🔐 Authentication

## Admin

- Username or email
- Password
- Google OAuth

## Teacher (Homeroom & Subject)

> Teachers must be **invited by Admin** via email before they can register. The system maintains a whitelist of invited emails — only whitelisted emails can create a teacher account.

- Username or email
- Password
- Google OAuth

## Student

> Students do **not** support Google OAuth, since younger students (SD) may not have a Google account.

Login options:
- NISN (National Student ID)
- System-generated username (combination of name + unique number, e.g., `budi.santoso.42`)
- Password

Username is auto-generated by the system on account creation and can be shared with parents/students.

> Self-registration is disabled. All accounts are created and managed by the school administrator.

### State Machine & Status Flow

#### Student Quiz & Submission Status
`NOT_STARTED` ➔ `IN_PROGRESS` ➔ `SUBMITTED` ➔ `GRADING_PENDING` (AI/Teacher Review) ➔ `GRADED` ➔ `PUBLISHED`

#### Monthly Progress Report Status
`DRAFT` (AI Generated) ➔ `UNDER_REVIEW` (Homeroom Teacher Review) ➔ `PUBLISHED` (Visible to Student)

#### AI Job Processing Status (Queue)
`PENDING` ➔ `PROCESSING` ➔ `COMPLETED` / `FAILED`

### Score Publication Flow

```
Raw Scores (DB)
      │
      ▼
Subject Teacher reviews (private, unpublished)
      │
      ├── Teacher edits if needed (remedial / additional tasks)
      │
      ▼
Teacher approves & publishes
      │
      ▼
Visible to Students
```
